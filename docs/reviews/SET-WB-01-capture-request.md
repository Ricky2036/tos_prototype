## 2. 逐包清单（DSH 按 A→F 交付，每包独立可用）

### 包 A · 入口与导航（决定 AG 接线点）
1. 真机上从设置首页找到「日期与时间」的**真实路径**：是「系统」组内一行，还是只能靠搜索，还是两者都有。
2. 该行的 UI 树节点（`resource-id` / `text` / `bounds` / `clickable`）、所在卡片分组标题、行内是否有副标题/当前值。
3. 首页 → 该行 → 落地页的点击序列录屏或逐帧截图。
4. 若真机还有第二个入口（搜索结果），同样给出结果行文本、点击后落地页是否同一个。
5. **unknown 标记**：入口是否受地区/运营商/SIM 状态影响。

### 包 B · 日期与时间主页默认态（决定页面骨架）
1. 落地页完整截图（整屏，勿裁切）+ UI 树 XML dump。
2. 逐行文本、顺序、分组标题、行右侧控件类型（开关 / 值 / 箭头 / 无）。
3. 导航栏：标题文案、返回键位置与图标、是否有右上菜单。
4. 关键控件 `bounds`（总开关、每个禁用行的可点区域）、字号量测、卡片圆角与左右边距。
5. **unknown 标记**：是否有折叠区、是否有「你可能想找」入口。

### 包 C · 总开关依赖（决定状态矩阵，最关键）
1. **自动确定日期和时间 = 开**：完整截图 + UI 树；逐行标注哪些行 `enabled=false` / 置灰 / 消失 / 仍可点。
2. **关**：完整截图 + UI 树；同样逐行标注。
3. 两态对照表：行名 / 开态可见性 / 开态可点性 / 关态可点性 / 关态点击后落到哪个选择器。
4. 开关本体：尺寸、开态/关态颜色、轨道与滑块几何（用于视觉对照）。
5. **unknown 标记**：切换瞬间是否有 toast、是否需要联网校验、是否有二次确认。

### 包 D · 返回与状态保持（决定 store 与 useBackHandler）
1. 在「关」态改一个值（如把 24 小时制切到另一侧）→ 返回上一页 → 再进入：该值是否保留。
2. 进入任意子页后按返回键 / 侧滑：分别落到哪里，是否需要二次返回。
3. 切到别的应用再回来，开关状态是否仍保留（判断是否需要持久化）。
4. **unknown 标记**：是否存在「应用未保存即退出」的提示。

### 包 E · 视觉标定（给 G8 / 像素对照）
1. 总开关、禁用行、分组标题三处的放大截图（标注像素比例）。
2. 页面底色、卡片底色、分隔线色、禁用态文字色的取色点。
3. 与既有设置页（显示与亮度）同位置控件的对照截图，确认是否复用同一套规范。
4. **unknown 标记**：是否有深色模式差异（若本轮不做则明确标为不做）。

### 包 F · 交互契约（每包都可附，最后汇总）
每条写成「起点 → 动作 → 可观察结果 → 截图/UI 树文件名」，例如：
`主页(auto=on) → 点总开关 → 日期行由禁用变可点 → C-on→off.png + C-off.xml`。
**不要写「看起来好了」**，每条都要能对照机器验收。
