落实既有协议：一个文件一个owner，单一事实源；共享主壳单点接线，独立页面并行；增量专项先验证，重型浏览器测试由现有租约串行；集成验收走真实首页入口，逐项确认目标、状态变化、取消/返回、重进、首屏与滚动截图。卡片/收件箱/通知只服务交付，不单独构成完成条件。
