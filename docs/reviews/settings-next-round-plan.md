# 下一批设置复刻目标与计划（待用户审核）

本文件是目标提案，不是已下发的业务开发任务。回调接入不等于批准此计划。

## 层级口径

- L0：设置首页。
- L1：从首页打开的模块首页，例如“系统”“安全和紧急情况”“账号和备份”。
- L2：模块内条目打开的页面，例如“日期与时间”“管理账号”。
- L3：日期选择器、时间选择器等更深操作。

## 建议目标

第一批先做到 **L0→L1 全部入口可达、目标正确、可返回；补齐系统/安全/账号三个明显缺失或失真的 L1 页面**。不能宣称所有设置深度复刻完成。

第二批再做原定三模块的 L2/L3 完整链路；第一批探索时就登记其菜单树、缺失证据与排除项，避免再出现做完默认页才发现后面一大片未知。

Google 独立服务沿用原任务暂缓，首页对应入口需在验收清单明确列为例外；不能计入已完成分母。是否改变这一排除项由用户审核。

## 资源与验收

真机按功能包预约，采完一个分支就释放；等设备时使用已有证据开发。开工先列所需文件，公共入口由单点接线或明确文件借用，独立页面并行。重型浏览器回归串行。

每包提交菜单覆盖表、前后对照、完整进入/返回走查与对应测试；另一人交叉审查后集成。最终在9999核对全部本批范围与明确排除项，再交用户体验。完成事件走正式回调入口，收件成功与任务完成分开记录。

不预报未经摸底的小时数；首个包交付后根据实际采集/开发/等待时间更新剩余安排。衡量可验收页面与漏项返工，不衡量三人是否一直显示忙碌。
