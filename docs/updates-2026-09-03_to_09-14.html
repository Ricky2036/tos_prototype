五工程与协作

这 12 天的另一条暗线：三个人工智能体在同一个仓库里并行开发，靠一套书面协议避免互相踩踏。

多智能体工作区协议

  • 按 worktree 目录名识别角色（Workbuddy / Codex / Antigravity / 集成）
  • 共享锁清单：package.json、App.vue、main.js、apps.js、registry.js、ScreenView、AppWindow、HomeScreen、两个 store、两份全局样式、英雄动画与几何工具
  • 改共享文件前须在 ACTIVE_TASKS.md 登记独占所有者
  • 提交只 stage 显式路径，禁用 git add -A；禁止改他人改动
  • 交接须报告：任务名 / 分支与提交号 / 变更文件 / 测试结果 / 风险 / 锁可否释放
  • 集成由 Antigravity 逐条 cherry-pick → 验证 → 发布 main

质量保障

  • 单元测试 25 个文件、200 条断言（几何纯函数、弹簧、store）
  • 端到端 32 个脚本；其中切换器专项 187 条断言，全绿
  • e2e 覆盖真实触摸（CDP Input.dispatchTouchEvent）—— 桌面鼠标复现不了的触摸缺陷必须走这条路
  • 每项几何改动都要求「改前基线 → 改后实测」的数值对照，不接受「感觉好了」
  • 开发端口 5555；构建走覆盖配置（不清空 dist、自动回收最旧产物）
