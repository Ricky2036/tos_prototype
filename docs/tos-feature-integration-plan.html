① 结论：为什么不能直接 merge

两份快照的基线不是当前 HEAD 的祖先（可追溯的历史起点就是 4150774，它是重写后的 root commit）。对 73 / 72 个 src 文件逐一比对历史里全部 831 个提交，最高命中只有 57/73。命中不满的那 16 个文件里，8 个是快照时代根本还不存在的文件（DynamicIsland.vue、SettingsDND/Prayer/Sound.vue、PhotoWidget.vue、SmartSuggestionWidget.vue、i18nStore.js、prayerStore.js）。

⇒ 没有共同祖先，git merge 不可能；只能按功能语义逐个重放。

判定方法（可复用）

# 1. 在历史里反查快照基线
git hash-object <快照文件>                      # 得到坏对象未入库的 blob sha
git log --all --oneline --find-object=<blob>   # 该 blob 在哪个提交出现过

# 2. 对全部提交打分：快照里有多少文件恰好等于该提交的 blob
#    （脚本见 skill: snapshot-fork-archaeology/scripts/find_fork.py）

# 3. 以最高分提交为近似基线，逐文件判定四类
#    NEW / PURE-FEATURE / BOTH-CHANGED / BASE-DRIFT-ONLY

控制中心接入点

  1. 把音量条的 @pointerdown="sliderPointer($event,'volume')" 换成 volumeSliderPointer：位移 > 7px 算拖动（照常调音量）；按住 500ms 不动 ⇒ openVolumePanel(track) 全屏面板。
  2. volumePct 改为 volumePlusLevel ? 100 : volume * 100，并新增 volumeDisplayPct（200 / 300 / 500%）与 volumePlusActive。
  3. 音量条加状态类 .cc-volume-slider + is-plus / plus-200|300|500 / anchor-hidden，以及 data-testid="volume-slider"。
  4. CC 磁贴表新增 { id:'power', icon:'power', label:'关机', activeColor:'#ef4444' }，onActivate('power') 里开菜单并收起 CC。

必须重推的几何：全屏面板的终态尺寸。

快照的假设是「控制中心音量条 = 88 × 138」，于是终态取了 width 88 × height 276（宽度不变、高度 ×2）。

当前仓库的格子是 BASE_CELL = 62 / BASE_GAP = 14 ⇒ 音量条实际是 62 × 138（高 = 2 格 + 1 缝 = 2×62+14）。高度 138 恰好没变，宽度 88 → 62。

所以终态 width 不能抄 88。建议改成从锚点运行时测量（openVolumePanel(track) 本来就传了真实 rect），终态宽度沿用该 rect 宽度，高度保持 2 × rect.height —— 这样也和宫格整体缩放（gridScale 0.9–1.24）天然兼容。

可搬运的验收契约

tests/volumePlus.test.js 里有 7 个用例，覆盖 Plus 阶梯（0→2→3→5→封顶）、下滑退出、滑块拖动退出、侧栏状态机（hidden/expanded/compact/panel/media 的跃迁与 pulse 计数）、通道切换与辅助音量步进、按应用静音引导。它只 import controlStore，可以直接搬过来跑，是这次集成里最值钱的资产。

⑤ 功能二 · 超级省电集成方案

入口与渲染路径

快照的入口是 CC 里的 boost 磁贴：onActivate('boost') ⇒ control.enterSuperPower() + 收起 CC。之后 CC 用 v-if="control.superPower" 换一整套版式（SUPER_CONNECTIVITY + SUPER_SHORTCUTS 极简快捷卡），并支持长按磁贴弹出 superDetail 二级面板（带 anchor-* 类做锚点飞入）。主屏由 ScreenView.vue 里的 <SuperPowerHome v-if="control.superPower" /> 承载。

入口语义要重选。当前 CC_LABELS 里 boost 的中文是 「灯效」（英文 Light Effect）—— 拿它当超级省电入口属于语义劫持，三语文案会自相矛盾。

更自然的选择是 batterySaver（batterySaver: '省电'）：短按 = 普通省电，长按 = 进超级省电，这和快照里 A 改动 batterySaver 磁贴配色（白底蓝字）的意图也对得上。

换皮会绕过新能力。superPower 打开时 CC 整体改用另一套版式，会绕过微调模式（图标/底板尺寸覆盖）、布局预设（camon/note/gt）、宫格整体缩放与编辑模式。需要先定策略：进入超级省电时把这些能力整体禁用并给一句解释（推荐），还是在新版式里也兼容它们（成本高、收益低）。
