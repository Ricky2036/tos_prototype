功能全景：6 个域、76 项能力

同一批 9-03 → 9-14 的产出，换一个切法：不看时间，看「现在这个原型具备哪些能力、各自是什么性质的变更」。
每项能力标注了 新增 / 重做 / 打磨 / 修复 四种性质之一。

一先分三层看

76 项能力不属于同一类工作。按「做出来 / 做顺手 / 做像」分层，能看清这 12 天的力气花在哪。

Layer 1

基础能力 · 从无到有

原型此前没有的整块功能。这一层决定「能不能演示」。

桌面分页 / 文件夹 / 小组件 多任务切换器 锁屏堆叠通知 动态岛实时活动 控制中心编辑模式 时钟完整 App

Layer 2

交互质量 · 做顺手

功能已经有了，但手感不对。这一层决定「像不像真机」。

快滑惯性 / 慢滑一次一张 停驻手势进入 弹簧物理统一 跟手连续性 触摸手势判定 挤压三分量

Layer 3

视觉还原 · 做像

和参考稿 / 原生系统的一致性。这一层决定「能不能拿出去看」。

图标矢量体系 + 光学尺寸 4 层磨砂玻璃 网格几何与行列间距 圆角 / 投影 / 亮度阶梯 钛金属外框

二功能域详解

以下按 6 个功能域展开。标签含义：新增 本期首次实现 · 重做 方案被推翻重建 · 打磨 按参考稿持续精修 · 修复 缺陷闭环。

四一句话总结

功能面：原型的「骨架」在这 12 天补齐了 —— 桌面（分页 / 文件夹 / 小组件 / 编辑模式）、多任务切换、锁屏堆叠通知、动态岛实时活动、控制中心编辑与预设体系、时钟完整 App。剩下偏基础的是 相机 / 信息 / 电话 / 日历 这几个应用。

质量面：重心从「有没有」转到「像不像」。五条阶段级缺陷都闭环了（安卓触摸误判、点卡闪跳、删卡后图标消失、入场不同步、横滑抖动），其中三条的共同教训是参照系或状态归属选错，而不是动效参数不对。

方法面：多任务切换器 17 轮里，后半程每轮都建立了「探针实测 → 改前基线 → 改后复测 → e2e 锁死」的闭环，并有专项 187 条断言兜底；这条工作方式本身可以复用到其余模块。
