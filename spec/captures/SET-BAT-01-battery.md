## 二、实测交互

| 操作 | 结果 |
|---|---|
| 点省电/均衡模式卡 | 立即切换，无确认、无 toast；剩余时间变化；设备同时开深色主题/60Hz/15 秒息屏 |
| 电池模式 ⓘ | 底部说明卡，「确定」关闭 |
| 过去 7 天 | 「电池电量」→「用电量」，活动时长变「日均…」，排行标题变 7 天 |
| 查看更多 | 卡片内联展开（QQ / Google Play 商店 / 闲鱼 / 相机…） |
| 排行行 | 进应用耗电详情；返回回列表 |
| 无限制 | 立即选中，无确认 |
| 强行停止应用 | 两次截屏（0.4s / 1.2s）均无弹窗、无 toast（是否执行 unknown） |
| 自动开启省电模式 | 关 →「自动开启电量」滑杆置灰；开 → 可拖 |
| 返回 | 省电/充电/健康 → 电池首页 → 设置首页；设置首页保留滚动位置 |
| 重进 | 电池模式保持上次选择（省电模式） |
