## 包 D · 返回与状态保持

| 场景 | 实测结果 |
|---|---|
| 时区列表 → 返回 | **一次返回**回到「日期与时间」，不需二次返回 |
| 日期与时间 → 返回 | 回到「系统」页（`SystemDashboardActivity`） |
| 返回 → 首页 → 重进 | **一次返回**到系统页，再返回到设置首页 |
| 改「使用 24 小时制」→ 返回首页 → 重进 | **状态保持**：`checked` 仍为 `true`（离开前改的） |
| 改总开关 → 返回 → 重进 | 保持（同上，`checked` 一致） |

结论：三处状态均由系统持久化，**原型需要 store 持久化**，不能只放在组件内 state。
