### 7.3 录屏清晰度 / 帧率

两个都是**底部单选弹层**（标题居中 + 选项 + 取消胶囊），选项圈是空心圆环、选中填蓝。

- 清晰度 = 超高清 (2K) / 超清 (1080P) / 高清 (720P) —— **没有 480P**（上一轮按同族猜的 480P 已撤）
- 帧率 = 高帧率 (60 FPS) / 低帧率 (24 FPS) —— **没有 30FPS**

值列排版：真机值列只有约 80 设计 px 宽，`超清 (1080P)` 单行放得下，`低帧率 (24 FPS)` 会折成两行。
