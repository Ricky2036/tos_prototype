## 2. 版式（真机截图口径）

1. **页面底色 `#F7F7F8` + 白卡**（圆角 20、卡间距 14），与设置其它页同一套语言。
2. **行高 54**、行内左右 16 → 文字落点 x=32（页面 16 + 行内 16）。带副标题的行 72。
3. **标签页是分段控件**：灰轨道 `#EDEDEF`（高 38 / 圆角 19）+ 白色胶囊（1px 浅边 + 轻投影），**不是下划线标签页**。
4. **柱状图有横向虚线网格**（每条刻度一条，`repeating-linear-gradient` 3/4 断点，`#E5E5E8`），纵轴刻度右对齐在右侧 44 宽空档。
5. **开关是 Material 轨道**（46×26 / 滑块 22 / 点亮 `#2F6BF6`），不是设置里的 iOS 绿。
6. 图表卡把「分段控件 + 已用流量 + 柱图 + 脚注 + 应用用量行」装在同一张卡里；「+N」是 38px 灰圆胶囊。

## 4. 数据自洽（单测咬住）

- 七日柱之和 = 主页「过去 7 天」总量 = **166.0 MB**
- 应用用量之和 = 同一总量；名单取自桌面注册表（38 个），不另写
- 周报的柱与「已用流量」同源（录屏里周报用的是另一周 6.5 MB，与主页对不上；这里统一成本周）
- 今天恒为 0.0 B（录屏原样）
