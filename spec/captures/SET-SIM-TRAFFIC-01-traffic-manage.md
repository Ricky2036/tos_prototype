## 2. 与设置其它页不同的三条硬约束

1. **底色是纯白**，不是设置的 `#F0F1F2`；行与行之间**没有分隔线、没有卡片**（白底白卡，视觉上只剩文字）。
2. **行高 48**、行内左右 16 → 文字落点 x=32（页面 16 + 行内 16）。带副标题的行 64；「设置」首行与「日流量限额」在真机上是 88（`.is-roomy`）。
3. **开关是 Material 轨道**（46×26 / 滑块 22 / 点亮 `#2F6BF6`），不是设置里的 iOS 绿。

## 4. 数据自洽（单测咬住）

- 七日柱之和 = 主页「过去 7 天」总量 = **166.0 MB**
- 应用用量之和 = 同一总量；名单取自桌面注册表（38 个），不另写
- 周报的柱与「已用流量」同源（录屏里周报用的是另一周 6.5 MB，与主页对不上；这里统一成本周）
